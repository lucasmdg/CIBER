# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] — 2024-11-15

### Added

- 37 proyectos de ciberseguridad organizados en 3 niveles + proyectos futuros
- **Nivel Básico (10 proyectos)**: Password Locker, Port Scanner, Hash Cracker, Log Analyzer, File Integrity Checker, Keylogger Demo, Caesar Cipher, Base64 Tool, Vulnerability Scanner, Network Sniffer
- **Nivel Intermedio (10 proyectos)**: Password Locker v2, Multithreaded Port Scanner, Directory Bruteforcer, Web Login Bruteforce, Packet Sniffer Avanzado, ARP Spoofer Detector, Basic IDS System, Web Vuln Scanner, SSH Bruteforce, Log Monitor System
- **Nivel Avanzado (10 proyectos)**: Custom C2 Simulator, Mini Metasploit, Advanced Password Manager, Network IDS, Web Pentesting Framework, Privilege Escalation Lab, Malware Analysis Lab, Ransomware Simulator, Threat Hunting Lab, Red Team Lab
- **Proyectos Futuros (7)**: Simulador APT, Analizador Malware IA, Red Team Framework, SIEM Dashboard, Honeypots Interactivos, Phishing Manager, Mapeador Superficie Ataque
- SentinelX SOC Dashboard con Next.js 14, Prisma, NextAuth.js
- Suite de tests unificada con 29/29 tests pasando
- Wiki completa con 40+ páginas de documentación técnica
- README profesional con badges, TOC, tablas de proyectos, arquitectura
- GitHub issue templates (Bug Report, Feature Request, Question)
- Pull request template con checklist
- Dependabot configuration para dependencias Python y npm
- GitHub Actions CI para Python y SentinelX
- EditorConfig, .gitignore mejorado, Prettier config
- SECURITY.md con política de vulnerabilidades
- CODE_OF_CONDUCT.md (Contributor Covenant)
- ROADMAP.md con hitos planificados
- FAQ.md con preguntas frecuentes
- CONTRIBUTING.md con guía de contribución

### Infrastructure

- CI pipeline con linting, tests, cobertura en 3 sistemas operativos
- Release workflow automatizado
- Dependabot para Python (pip) y npm
