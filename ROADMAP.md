# Roadmap

## Visión

Convertir CIBER en el laboratorio de ciberseguridad open-source de referencia en español, con una ruta de aprendizaje completa desde fundamentos hasta operaciones Red Team / Blue Team.

## v2.0 — Actual (Nov 2024)

- 30 proyectos básicos/intermedios/avanzados completos
- SentinelX SOC Dashboard funcional
- Wiki con 40+ páginas de documentación
- Suite de tests automatizada
- CI/CD con GitHub Actions

## Cómo Influenciar el Roadmap

1. **Vota** issues con reacciones (👍)
2. **Sugiere** proyectos en [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)
3. **Participa** en [Discussions](https://github.com/lucasmdg/CIBER/discussions)
4. **Contribuye** con pull requests
